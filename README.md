# College Website Project

A responsive and user-friendly college website designed and developed entirely by me. This project showcases a professional-looking web presence for an educational institution, with all the core features a college website needs.

# Features

- Home page with college introduction
- About, Courses, and Departments pages
- Student and Admin login portals
- Event announcements and contact form
- Fully responsive design for all screen sizes

# Tech Stack

- HTML, CSS, JavaScript
